# Week 6 — Анимация және гравитация

## Жұмыстың мақсаты

Бұл зертханалық жұмыста OpenGL көмегімен уақытқа тәуелді анимация жасау, гравитацияны физикалық формула бойынша модельдеу және екі объектінің қозғалысын бір-біріне сәйкестендіру үйренілді.

## 1. Жобаның сипаттамасы

Бағдарлама C++, OpenGL 3.3 Core Profile және GLFW кітапханасымен жазылды, macOS жүйесінде іске қосылады. Терезе өлшемі — 800×600.

Сахнада үш элемент бар:

- Көк блок экранның төменгі жағымен **оңнан солға** қарай қозғалады.
- Сары-қызғылт сары шар гравитация әсерінен жоғары-төмен секіреді.
- Жер сызығы объектілердің тірелетін деңгейін көрсетеді.

## 2. Блоктың қозғалысы

Блок тұрақты жылдамдықпен қозғалады. Қозғалыс циклін `fmod` қайталап отырады:

```cpp
float boxTime = std::fmod(elapsed, boxPeriod);
float boxX = startX - boxSpeed * boxTime;
```

- `elapsed` — бағдарлама басталғаннан бергі уақыт (`glfwGetTime()`).
- `boxPeriod` — блоктың бір толық өту уақыты.
- `boxSpeed = travel / boxPeriod` — қозғалыс жылдамдығы.

Блок сол жақ шекарадан толық шыққанда оң жақтан қайта пайда болады.

## 3. Шардың гравитациямен секіруі

Шардың биіктігі мына формуламен есептеледі:

$$h(t) = v_0 t - \frac{g t^2}{2}$$

Мұндағы $v_0$ — бастапқы жылдамдық, $g$ — гравитациялық үдеу, $t$ — секіру басталғаннан бергі уақыт.

Бастапқы жылдамдық қалаған ең үлкен биіктік $h_{max}$ арқылы алынады:

```cpp
const float v0 = std::sqrt(2.0f * gravity * maxHeight);
const float bouncePeriod = 2.0f * v0 / gravity;

float h = v0 * ballTime - 0.5f * gravity * ballTime * ballTime;
float ballY = groundY + ballRadius + h;
```

Шар көтерілгенде баяулайды, ең жоғарғы нүктеден кейін төмен қарай үдейді, жерге жеткенде цикл қайталанады.

## 4. Қозғалыстарды синхрондау

Блок пен шар түйіспеуі үшін блоктың цикл уақыты шардың **екі** секіру периодына тең етілді:

```cpp
const float boxPeriod = 2.0f * bouncePeriod;
```

Одан кейін шардың фазасы блок экран ортасынан (x = 0) өткен сәтте шар **ең жоғарғы нүктеде** болатындай ығыстырылды:

```cpp
float tCenter = startX / boxSpeed;
float ballTime = std::fmod(elapsed - tCenter + bouncePeriod * 0.5f, bouncePeriod);
```

Ең жоғарғы нүктеде шардың төменгі шеті блоктың үстінен жоғары болады, сондықтан соқтығысу болмайды.

## 5. Vertex және Fragment Shader

Vertex Shader объектінің өлшемін, орнын және терезенің арақатынасын (aspect ratio) ескереді, сондықтан шар сопақ болып кетпейді.

```glsl
layout(location = 0) in vec2 aPos;
uniform vec2  uPos;
uniform vec2  uSize;
uniform float uAspect;

void main()
{
    vec2 p = aPos * uSize + uPos;
    gl_Position = vec4(p.x / uAspect, p.y, 0.0, 1.0);
}
```

Fragment Shader түсті `uColor` uniform арқылы алады:

```glsl
out vec4 FragColor;
uniform vec3 uColor;

void main()
{
    FragColor = vec4(uColor, 1.0);
}
```

Блок — көк, шар — сары-қызғылт сары, жер сызығы — сұр түспен салынды. Бір ғана блок және шеңбер геометриясы әр объект үшін қайта қолданылады (`uPos`, `uSize` арқылы).

## 7. Бағдарламаны іске қосу (macOS)

Алдымен құралдарды орнату (Homebrew арқылы):

```bash
brew install cmake glfw
```

Жобаны құрастыру және іске қосу:

```bash
cmake -S . -B build
cmake --build build -j
./build/bin/week6
```

Бағдарламадан шығу үшін `Esc` пернесін басыңыз.

## Қорытынды

Week 6 жұмысында екі объектінің анимациясы жасалды. Блок көлденең бағытта үздіксіз қозғалады, ал шар $h(t) = v_0 t - gt^2/2$ формуласына сәйкес гравитация әсерінен секіреді. Блоктың периодын шардың екі секіру периодына тең ету және шардың фазасын ығыстыру арқылы екі қозғалыс бір-біріне сәйкестендірілді, соның нәтижесінде блок шардың астынан соқтығыссыз өтеді.
